Tailwind v4 theme

Drop tokens into app/globals.css.

@import "tailwindcss";

@theme {
  /* Surfaces */
  --color-bg:              #000000;
  --color-surface:         #0A0A0A;
  --color-surface-raised:  #111111;
  --color-border-subtle:   rgba(255,255,255,0.06);
  --color-border-medium:   rgba(255,255,255,0.10);

  /* Text */
  --color-text:            #F0F0F0;
  --color-text-secondary:  rgba(255,255,255,0.55);
  --color-text-tertiary:   rgba(255,255,255,0.30);

  /* Accents */
  --color-cyan:            #00E5FF;
  --color-amber:           #FFAB00;
  --color-green:           #00E676;
  --color-red:             #FF3D3D;

  /* Fonts (pair with next/font in app/layout.tsx) */
  --font-sans: "DM Sans", ui-sans-serif, system-ui;
  --font-mono: "JetBrains Mono", ui-monospace, monospace;

  /* Radii */
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 14px;
}

/* Cyan glow utility (no drop shadow — invisible on OLED) */
.shadow-cyan { box-shadow: 0 0 20px rgba(0,229,255,0.30); }

Shared layout

One nav, one footer, every page.

// app/(public)/layout.tsx
import { DM_Sans, JetBrains_Mono } from "next/font/google";
import Nav from "@/components/nav";
import Footer from "@/components/footer";

const sans = DM_Sans({ subsets: ["latin"], variable: "--font-sans" });
const mono = JetBrains_Mono({ subsets: ["latin"], variable: "--font-mono" });

export default function PublicLayout({ children }: { children: React.ReactNode }) {
  return (
    <div className={`${sans.variable} ${mono.variable} bg-bg text-text min-h-screen`}>
      <Nav />
      <main>{children}</main>
      <Footer />
    </div>
  );
}

Conversion steps

How to do it.

01

Port the tokens.

Copy styles.css custom properties into app/globals.css under @theme. Rename to Tailwind v4 conventions (--color-*, --font-*, --radius-*). Mirror in lib/design-tokens.ts for JS access.

02

Extract Nav + Footer.

Identical across all six pages. Pull into components/nav.tsx and components/footer.tsx. Use Next.js <Link> for internal routes; usePathname() drives the active state.

03

Componentize the primitives.

Eyebrow, Button (3 variants), Card (3 variants), Pill, Stat, FaqItem. Thin wrappers with cva() or clsx. Don't over-componentize copy — let pages stay as pages.

04

Calculator becomes a Client Component.

Mark reconstitution-calculator.tsx with "use client". Lift inline JS state into useState. Move math into pure functions in lib/calc.ts — easy to unit-test. The SVG syringe is a child component receiving { units, max, overflow } as props.

05

Waitlist form → API route.

app/api/waitlist/route.ts handles the POST. Validate with Zod. Hand off to Resend / Loops / Supabase. Add Cloudflare Turnstile if bots start finding it.

06

SEO + metadata.

Use Next.js export const metadata per page. One opengraph-image.tsx at the (public) root covers all six routes — pure type on black, generated via ImageResponse.

07

Ship.

Static export works (no auth on this surface). Deploy Vercel or Cloudflare Pages. Point protocomp.com at it; app.protocomp.com stays a separate subdomain for the app.

Sample primitive

Eyebrow component.

// components/ui/eyebrow.tsx
export function Eyebrow({ children, tone = "cyan" }: {
  children: React.ReactNode;
  tone?: "cyan" | "muted" | "amber";
}) {
  const color = {
    cyan:  "text-cyan",
    muted: "text-text-tertiary",
    amber: "text-amber",
  }[tone];
  return (
    <p className={`font-mono text-[11px] font-medium uppercase tracking-[1.2px] ${color}`}>
      {children}
    </p>
  );
}

Watch-outs

Things to not change in the port.

  • Keep flat colors. Don't let anyone add gradients "to make it pop" — the brief is explicit.
  • Numbers stay in JetBrains Mono. If you see a body-font number in a stat block, fix it.
  • The kill list (streaks, badges, fake testimonials, AI-powered marketing copy) survives the port.
  • Eyebrows are 11px exactly. Not 12. Not 10. The hierarchy depends on it.
  • Cyan glow replaces drop shadow everywhere. OLED screens swallow shadows.
  • The disclaimer ("Educational tool only…") stays on every page that mentions doses, compounds, or labs.
